# JERP — сценарий и режиссура следующего ролика

**The Unsupported Leap · 49 секунд · английская озвучка · preproduction v1.0**

Один пример объясняет проблему: AI превращает бесплатный trial в обещание «free forever». JERP проверяет утверждения по источнику и возвращает агенту компактные факты. 3D-метафора: уверенная фраза выходит за край собственного основания.

## Чего этот пакет не утверждает

Это не новый готовый MP4. Предыдущий [30-секундный ролик](../output/jerp-marketing.mp4) — отдельный ранний эскиз, его сценарий и визуальную систему новая разработка заменяет.

Пример вымышленный, помечен illustrative. Авторизованных вызовов JERP MCP не было. Шесть PNG — композиционные исследования на CSS с исходными шрифтами, а не шесть законченных Blender-шотов. `boards/orb-lookdev.png` — отдельный настоящий Blender-рендер; `lookdev.py` — его исходник.

## Структура

- `data/story.json` — единый источник сценарного тайминга и текста.
- `build_documents.py` — собирает сценарий, VO-cues, цитаты и manifest.
- `build_review.py` — собирает `review-deck.html`.
- `boards.html` — композиционные styleframes с локальными шрифтами; размеры 1920×1080.
- `brand/` — оригинальные ассеты, исходные и вычисленные токены, CSS wordmark.
- `research/` — первичные снимки страниц/контракта и карта доказательств. Материалы могут измениться на сайте; сохранена версия исследования.
- `boards/` — шесть PNG, contact sheet и Blender-lookdev.

## Воспроизведение

Из `/workspace/jerp-test`:

```sh
python video/preproduction/build_documents.py
python video/preproduction/build_review.py
blender -b -t 4 --python video/preproduction/lookdev.py
```

HTML использует локальные ассеты. Для просмотра можно запустить локальный HTTP-server из этой папки и открыть `boards.html` / `review-deck.html` в браузере. В облачном чате для просмотра используйте опубликованные файлы GitHub; localhost-ссылка не является пользовательским preview.

PDF экспортирован Chromium с print backgrounds и page size 1280×720 CSS px; 14 страниц без overflow. Субтитры — сценарные интервалы, а не speech-aligned финальный файл.
